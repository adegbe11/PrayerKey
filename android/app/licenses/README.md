# Bundled font licences

- `EBGaramond-OFL.txt` — SIL Open Font License 1.1, covering
  `app/src/main/res/font/eb_garamond.ttf`.

The OFL permits bundling and redistribution in a commercial application. It
requires the licence text to travel with the font, which is what this
directory is for; the font is not renamed, and nothing here needs to be shown
to users.
